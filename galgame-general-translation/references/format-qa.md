# 脚本保护、通用性与验证

## 通用的范围

本技能的翻译／审核方法可复用于不同作品；两个 Python 辅助脚本只通用到约定的数据结构，不是即插即用的全引擎汉化器。`check_units.py` 读取标准化源译 JSONL；`term_audit.py` 读取本技能格式的术语 JSONL。它们不解包、不解密、不直接回填引擎，也不判断错译或剧情连贯性。

更换作品时，重新确认提取／回填方式、编码、保护规则、字段映射和词表。已经正确转换为约定格式的数据可复用检查器；仅拿到未识别的脚本或二进制包时不能直接运行并声称兼容。首个小样须验证原文提取—回填一致及中文支持；缺少工具时记录阻塞，保留源文件，不假装完成。

脚本只提供确定性检查，译文质量由 [review.md](review.md) 规定的原文对照审核负责。即使把“不会去”错译成“会去”，只要结构未变，结构检查也可能全部通过。

## 提取与回填

只翻译引擎确认的可见文本字段。保留内部角色 ID、文本 ID、标签／命令名、跳转、条件、变量、资源路径、语音／立绘／背景标识与程序注释。姓名显示字段可译，不代表角色内部 ID 可改；`？？？` 不可提前替换真名。

以语法／项目解析器区分普通字符串与控制内容，不对整份脚本盲目正则替换。保留源文件，先用小样验证提取—翻译—回填；读出编码、BOM、换行与转义规则，不能默认一切都是 UTF-8。中间 JSONL 用 UTF-8，不意味着成品引擎文件也改编码。

逐单元保留 ID、场景、路线、说话者、选项和配音对应，不擅自合并／拆分可点击文本框。选项不增加选择结果、道德判断或承诺，维持同组选项粒度和主角口吻。

占位符如 `{name}`、`${name}`、`%s`、`%d`、反斜杠转义以及等待／颜色／速度等标签保留语义、数量和参数。默认保持控制序列；只有引擎规范和任务明确允许时才能调整命名占位符位置或换行。不要把 ruby 的显示读音／基字误当控制名；只在确认语法后改可见部分，保留功能。

同一引擎指令嵌在句中时，停顿与配音拍点也是约束。文字框超长先压缩中文冗余，不能删剧情；无法既完整又适配时记录真实限制，不悄悄截断。

## 技术完成条件

核对源译单元数、唯一 ID、顺序、路线／说话者等不可译字段；检查占位符、受保护标签、转义、编码和可解析性。使用引擎已有回填器／编译器，并核对未翻译、空译、乱码和超长候选。

“原译相同”不自动等于漏译：人名、数字、符号和有意保留的表达允许相同，需要有范围明确的例外。“没有日文字符”也不能证明已译完整。全量覆盖以 ID 映射和实际语义校订记录为准。

检查结果只声明实际覆盖：数据对齐、语法解析、编译、游戏实测是不同层次。通用脚本不能证明跳转正确、文本不溢出、配音合拍或语义正确。

## 可选确定性检查器

优先项目现有工具。缺少轻量比对时可用 `scripts/check_units.py` 检查“标准化 JSONL 对”，它不解析任何专有游戏引擎，也不翻译文本。

每行一个对象，必须有唯一字符串 `id` 与字符串 `text`；其他键都是不可译元数据，源译须完全相同。ID 应包含文件／场景命名空间，避免跨文件重号。允许空源单元，但源非空而目标空为错误。

```json
{"id":"common.ks#0042","speaker":"CH_01","route":"common","text":"こんにちは、{name}。"}
```

只将可译内容放 `text`；角色名栏需要译时也单独成为带独立 ID 的可译单元，不把需要翻译的字段塞到不可变元数据中。源侧与译侧元数据应分别由各自成品提取，不能把源元数据照抄到译侧后拿它证明成品没变。

```text
python "<skill目录>/scripts/check_units.py" source.units.jsonl target.units.jsonl --protected-patterns protected-patterns.json --report qa.json
```

保护规则文件是“Python 正则表达式字符串数组”，按已经确认的引擎写，匹配不可改变的控制片段。可把 `assets/protected-patterns.example.json` 作为起点，但**必须先验证样例确实适用于该引擎**；示例不覆盖全部标签、控制符或占位符语法。脚本按字符位置比较被匹配片段的序列及精确内容，遇重叠规则停止报错，避免模糊保护边界。

未提供保护规则时只做结构／元数据对齐，并在报告中标明没有做标签保护检查。脚本不使用“万能标签正则”来假装支持所有 Galgame 引擎。

可选参数：`--max-chars N` 仅产生字符长度候选，不等于像素宽度；`--allow-unchanged ids.json` 用确切 ID 数组排除有意不变的单元。未经复核的相同文本、替换符 `�` 和超长文本列为警告。

退出码：`0` 无结构错误（仍须处理警告）；`1` 对齐／元数据／控制片段等错误；`2` 输入或配置错误。报告含路径、文件哈希、计数、错误／警告总数与有限示例，不修改源文和译文。保护规则完整性、编码回写和游戏内可用性必须另行验证。
